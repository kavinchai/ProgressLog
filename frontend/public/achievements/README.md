# Achievement drawings

One drawing per weight milestone ("about the weight of an elephant"). The app
shows them on the Achievements screens and on the sheet after a workout.

To use your own drawing, replace a file here with yours under the same name.
No code changes are needed.

| File | Milestone | Weight |
| --- | --- | --- |
| piano.svg | Grand piano | 1,000 lbs |
| car.svg | Car | 4,000 lbs |
| elephant.svg | Elephant | 13,000 lbs |
| t-rex.svg | T. rex | 18,000 lbs |
| school-bus.svg | School bus | 25,000 lbs |
| boeing-737.svg | Boeing 737 | 90,000 lbs |
| space-shuttle.svg | Space shuttle | 165,000 lbs |
| blue-whale.svg | Blue whale | 300,000 lbs |

Tips:

- SVG works best: it stays sharp at every size. Keep a wide canvas, about
  160 × 104, with the drawing filling it.
- They sit on white and on the dark celebration card, so pick colors that read
  on both.
- To add, rename or reorder milestones, or change their weights, edit
  `src/config/volumeMilestones.json`. Each entry's `art` names its file here.
